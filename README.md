# 🍔 Zomato/Swiggy Food Delivery Analysis - Oracle SQL

> Real-world food delivery data analysis using Oracle 11g

### 📊 About Project
This project analyzes Swiggy/Zomato style data to find business insights like top restaurants, city-wise sales, and loyal customers.

### 🗃️ Database Design
- **users** - Customer details
- **restaurants** - Restaurant info
- **orders** - Order transactions

### 🔍 Key Queries Solved (11g Compatible)
1. City-wise total orders
2. Top performing restaurant (using ROWNUM)
3. Average order value per city
4. Loyal customers with >2 orders
5. Highest rated restaurant

### 🛠️ Tech Used
Oracle SQL 11g, JOINS, GROUP BY, ROWNUM, Aggregations
